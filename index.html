Preguntas frecuentes

Resuelve tus dudas sobre el curso y descubre qué necesitas para comenzar a diseñar páginas web con CSS.

¿Qué es CSS?

CSS (Cascading Style Sheets) es un lenguaje que permite definir la apariencia de una página web. Con CSS puedes cambiar colores, fuentes, tamaños, márgenes, fondos y distribución de los elementos HTML. También permite crear diseños adaptables, transiciones y animaciones.

¿Qué aprenderé en este curso?

Aprenderás desde los fundamentos de CSS hasta técnicas modernas de diseño web. Estudiarás selectores, propiedades, el modelo de caja, Flexbox, CSS Grid, diseño responsivo, animaciones y transiciones. También conocerás Sass y practicarás mediante ejemplos para aplicar lo aprendido en tus propios proyectos.

¿Qué es CSS GRID?

CSS Grid es un sistema de diseño que permite organizar los elementos de una página en filas y columnas. Es especialmente útil para crear estructuras como galerías de imágenes, tarjetas, paneles y diseños completos de sitios web.
